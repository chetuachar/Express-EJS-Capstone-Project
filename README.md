# 😂 Random Joke App

A simple Node.js + Express web application that displays a random programming joke using EJS templating.

---

## 🚀 Features

- Built with Express.js
- Uses EJS for rendering dynamic HTML
- Displays jokes with setup and punchline
- Styled with CSS
- Supports "Get Another Joke" functionality

---

## 📦 Installation

### 1. Clone the Repository
```bash
git clone https://github.com/chetuachar/Express-EJS-Capstone-Project.git
cd Express-EJS-Capstone-Project
```
### 2. Install Dependencies
```bash
npm install
```

## ▶️ Running the App
```bash
node index.js
```
Then open your browser and go to
```
http://localhost:3000
```

